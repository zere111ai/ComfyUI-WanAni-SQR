## 2026-07-29 更新 — 音频、最终预览与队列等待优化

### Summary
统一 SQR 与 VideoHelperSuite 的 ffmpeg 来源，将最终合并视频回传到 Video Combine 实时预览，并在最终合并失败时保留恢复现场。

### Description

- 依次复用 `VHS_FORCE_FFMPEG_PATH`、已加载的 VideoHelperSuite ffmpeg、系统 ffmpeg 或 imageio-ffmpeg，不再要求 `ffmpeg` 必须位于系统 `PATH`。
- 音轨检测不可用时保留源音频输入，避免把“无法检测”误判成“源视频静音”。
- 最终音频重封装强制要求源音轨存在；音频失败会明确报错，不再静默生成无声文件。
- `sqr_merged_*.mp4` 合并成功后回传到所绑定的 `VHS_VideoCombine` 节点，供 ComfyUI 当前页面直接预览。
- 最终拼接或音频重封装失败时保留 checkpoint，不再错误显示为全部完成。
- 最终成品写入后再次检测音轨；“音轨检测存疑”“写入失败”“成品校验失败”分别输出明确日志，任一异常都不会把任务标记为完成。
- 分段完成状态轮询由 5 秒缩短为 1 秒，降低多分段任务之间的空等时间。
- SCAIL-2 `batch_size` 被强制修正为 `1`、或超过 20 FPS 且未连接插帧节点时，日志会给出明确警告。
- 新增「原片硬切」分段模式。该模式直接裁取当前源视频帧并跳过 KSampler、VAE 与 SAM3；原片临时切片会参与最终合并，日志同时显示完整文件路径。
- `WAN ANI DIRECTOR` 新增「当前分段视频帧」和「当前分段参考图」输出。推荐将驱动 SAM3 连接前者、参考图 SAM3 连接后者，队列会在每段提交前绑定到该段真实输入。
- 新增质量优先的模型微分段。Director 中的镜头段仍保留原提示词、参考图、Character Lock 和精确时间范围；超过 Wan 81 帧上下文的采样镜头会自动均衡拆成多个队列任务。开启连续过渡时，每个微分段以约 65 个可见帧为目标，使额外的 16 帧 SCAIL-2 接力仍控制在单个 81 帧模型上下文内。
- 分段落盘改为按需生成：关闭连续过渡时不再额外编码完整过渡视频或保存 latent；开启时也只为确实存在下一段的分段保存接力数据。
- 每段完成后清理已消费的过渡视频、旧 latent、临时参考图和隐藏完整视频，并释放 Python/CUDA 未使用缓存；最终合并成功后清理本次生成的分段中间视频。
- LH Video Cutter 同样复用 VideoHelperSuite 的 ffmpeg 路径，改善 Windows 便携环境兼容性。

更新后请重启 ComfyUI，并强制刷新浏览器页面。

推荐工作流连接：

1. `WAN ANI DIRECTOR.当前分段视频帧` → 驱动人物 `SAM3 Video Track.images`，并用于 SCAIL-2 的当前分段视频输入。
2. `WAN ANI DIRECTOR.当前分段参考图` → 参考人物 `SAM3 Video Track.images`。
3. 不再把固定的完整 `VHS Load Video` 或跨分段参考批次直接连接到上述 SAM3 输入。

## 2026-07-21 更新 — LH Image Editor 与跨环境队列回连

### Summary
新增可独立复用的参考图合成与精修节点，并让分段队列根据 ComfyUI 实际监听地址和端口提交后续任务。

### Description

- 新增独立 `LH Image Editor`，同时保留导演台内部原有的图片合成功能。
- 支持最多多张人物图与纯色或上传背景混合合成，并可按原始分辨率进行位置、缩放、水平翻转和中心旋转调整。
- 支持快速纯色抠图、可选 SAM3 高级抠图，以及笔刷大小可调的硬边/柔边人物橡皮擦；新加载人物图默认使用“不抠图”。
- 新增非破坏性的光线、颜色和细节调整，包括曝光、明暗层次、白平衡、饱和度、纹理、清晰度、锐化、降噪和模糊。
- 新增总亮度与 RGB 独立曲线，可添加、拖动和右键删除控制点，并支持单通道复位、最多 15 步撤销和可拖动的修改前后对比。
- 浏览器使用受限分辨率代理图进行轻量预览，最终合成时在后端按原始分辨率应用完整调整。
- 修复其他电脑使用自定义 ComfyUI 端口或监听地址时，后台分段队列错误回连 `127.0.0.1:8188` 并出现 `WinError 10061` 的问题。

更新后请重启 ComfyUI，并强制刷新浏览器页面。

## 2026-07-06 更新 — 导演台精细控制与 SCAIL-2 辅助工具

### Summary
增强 WAN ANI DIRECTOR 的逐段参考图处理、SAM3 单人物锁定、自动切镜检测和动态时间线管理，并确保 Color Match 结果真正进入 SCAIL-2 Multi Ref 生成链。

### Description

本次更新将导演台从分段与参考图管理器进一步扩展为 SCAIL-2 的精细控制入口：

- 每段可提取比例引导帧，并通过导演台新增的 `IMAGE` 输出单独连接到其他节点。
- 每张参考图可独立启用手动 Color Match 预览并填写强度；正式执行时使用与 `ColorMatchV2` 相同的 `mkl` 算法，将处理结果逐张接入实际 Multi Ref 输入，而不是只影响界面预览。
- 新增逐段 SAM3 手动打标。导演台自动提取分段首帧，支持正向人物点和负向排除点，并将归一化坐标转换为当前视频尺寸下的 SAM3 初始遮罩，从而锁定驱动视频中的单个人物。
- Load Video 的跳帧、帧率或抽帧设置变化后，旧 SAM3 打标帧会自动失效并重新提取，避免沿用错误画面。
- 新增轻量切镜检测：结合相邻帧灰度像素差异与颜色直方图距离，在当前分段内识别硬切镜并自动建立镜头段，便于逐镜头重新打标。
- 连续过渡开启时仍保持每段至少 60 帧；关闭连续过渡后，手动切片、边界拖动、平均分段和切镜分段不再受 60 帧限制。
- 分段按钮右侧新增直接关闭区域。超过 Load Video 当前有效总帧数的旧分段会显示警示边框，可单独移除且不改变其他有效分段范围。
- 修复分段参考图继承、人物替换状态、Video Combine 分段预览、无过渡硬切合并和中文日志编码等运行问题。

更新后请重启 ComfyUI，并强制刷新浏览器页面以加载新的 Python 节点、后端接口和导演台前端。

## 2026-07-05 更新 — WAN ANI DIRECTOR

### Summary
新增面向 WanAnimate 与 SCAIL-2 分段工作流的可视化导演台，可手动切分参考视频、为每段分配参考图和提示词、控制动作迁移或人物替换，并在排队生成前校准参考图中的人物比例。

### Description

`WAN ANI DIRECTOR` 是专门针对 WanAni SQR 执行方式设计的时间线控制台。它保留原有分段队列、断点续跑、音频处理、过渡接力和最终合并能力，同时将仅支持平均分段的操作升级为可视化编辑流程。

主要功能：
- 自适应参考视频预览，支持播放同步、时间线拖动、精确视频元数据，以及实时响应 `force_rate`、`skip_first_frames`、`frame_load_cap` 和 `select_every_nth`。
- 支持手动 Cut、拖动分段边界、每段最少 60 帧、独立分段颜色、删除后自动补齐，以及 1–100 段的手动平均分段。
- 每段可配置有序参考图组，支持拖拽排序、自适应缩略图、原始分辨率显示、人物/背景标记；后续空段会自动继承最近一段有效参考图。
- 非多参模式只传入第一张参考图，并强制作为普通人物参考；Multi Ref 模式传入完整有序图组，并联动 SCAIL-2 高级 Colored Mask 身份模式。
- 动作/表情迁移与人物替换采用全局控制，自动同步所有分段、Colored Mask Advanced 和 SCAIL-2 过渡节点。
- 每段可填写独立 Positive 提示词，并通过新的 `STRING` 输出连接到工作流；后续空提示词向前继承，第一段必须填写。
- 两种过渡策略：ON 保留视觉与 latent 平滑接力；OFF 让每段按照自己的参考图和连续动作视频帧独立生成，再按精确可见区间硬合并。
- 可在播放头位置提取比例引导帧，并进入参考图比例调整界面；参考图可半透明叠加、拖动、缩放，保存时维持原分辨率，缩小使用灰色补边，放大按原画布裁切。
- 支持每段 Video Combine 实时预览、浏览器 client 绑定、中英界面切换、节点自适应缩放、checkpoint 续跑、音频对齐和最终视频合并。

本次更新同时修改了 Python 节点结构、后端接口和前端扩展，更新后请重启 ComfyUI 并刷新网页。

## 2026-07-01 更新

### Summary
修复 Load Video 起始跳帧偏移，跨工作流记忆最近使用的分段数，并兼容不含音频流的源视频。

### Description

本次更新改进了分段队列的时间轴准确性和日常使用体验：
- 分段任务会保留 `VHS_LoadVideo.skip_first_frames` 的原始设置，并在此基础上叠加每一段的偏移，不再覆盖用户设置。这样跳过开头帧后，不会错误地变成缺少结尾帧。
- 音频切片使用同一套修正后的源视频偏移，保持画面与声音同步。
- 分段数会保存到浏览器本地设置。切换工作流后自动恢复最近一次使用的数值，不再回到默认值 `2`。
- 创建 `VHS_LoadAudioUpload` 节点前会检测源视频是否包含音频流。无音频视频会按静音视频继续运行，不再因音频提取失败而中断。
- 源视频无音频时，会清除完整片段和裁剪片段输出中的无效音频输入。

更新后请重启 ComfyUI 并刷新前端，使后端和界面修改同时生效。

## 2026-06-30 更新

### Summary
新增可断点续跑的文件夹图片批处理、逐张自动排队、节点进度条、底部文字边条，以及按照来源文件夹自动整理输出目录的 Flux.2 Klein 批量重绘流程。

### Description

新增节点：
- `LH Images Folder Loader`：保持每张图片原始尺寸；可记录文件夹图片总数、当前索引、文件清单、当前文件和运行批次。意外中断后会从最后成功保存的位置继续。
- `LH Save Image (Passthrough)`：每张图片保存成功后自动排队下一张；阻止旧任务重复保存；同步更新浏览器预览；支持日期路径，并自动创建“来源文件夹名-f2kmd”输出目录。
- `LH Image Footer Bar`：可控开关；支持白底黑字或黑底白字；可设置文字、边条高度、字号和左右留白；账号及长链接会自动缩小适配。

附带工作流：
- `example_workflows/f2k-reskin.json`：Flux.2 Klein 9B 文件夹批量风格重绘工作流，支持保持画幅比例的约 1.5MP 输出、逐张处理、断点续跑、进度显示、可选署名边条和自动输出目录。

稳定性改进：
- 自动任务携带明确图片索引，避免 ComfyUI 重复使用上一张图片缓存。
- 每次重置生成独立运行 ID，同一个文件夹可以反复完整重跑。
- 仅在图片成功保存后推进断点；旧任务不能让进度倒退或重复保存。
- 排序方式、起始索引和加载上限均纳入独立进度身份。
- 文件夹节点显示当前数量、总数、百分比和当前文件名。
- 本地运行进度文件不会提交到 Git。

一个适用于 ComfyUI Wan Animate / KJ Context 的自动化长视频生成节点,支持分段生成、无缝过渡、自动场景切换、断点续跑、自动合并和音频同步。

## 已整合过渡节点

原独立项目 `SQR-WAN-Transition` 的功能现已直接整合到本项目：

- `SQR WanAnimate Transition To Video`
- `SQR SCAIL2 Transition To Video`
- SCAIL2 动作迁移与 Replacement Mode 独立过渡策略
- 根据模型自动处理过渡视频读取、裁切、合并及音频偏移

安装本项目后不再需要同时启用旧的 `SQR-WAN-Transition` 插件，否则可能重复注册同名节点。

## ✨ 主要特性
- 分段生成:自动拆分长视频,避免显存不足错误
- 无缝过渡:使用上一片段的最后一帧保证流畅衔接
- 自动场景切换:支持多参考图风格/角色切换
- 断点续跑:中断后可从任意片段继续生成
- 自动合并:全部片段生成后自动拼接为完整视频
- 音频同步:自动提取并对齐原视频音频
- 预览模式:先查看分段计划再开始渲染

## 🚀 快速开始
1. 将 Load Video 的 frame_count 和 fps 连接到本节点
2. 设置分段数量,关闭 Run 先预览计划
3. 通过按钮绑定以下节点:
   - 源视频节点 (Load Video)
   - 输出节点 (VHS_VideoCombine)
   - 动作嵌入节点 (WanVideoAnimateEmbeds)
4. 打开 Run 开始自动生成

## 🛠 运行模式
- 预览:仅显示分段计划,不渲染
- 全新生成:从第1段开始渲染并自动合并
- 续跑:从中断处继续生成

## 📌 常见问题
- 节点ID为空:请通过按钮绑定必需节点
- 中断续跑:设置起始片段 → 选择最后视频 → 启用续跑
- 输出路径:output/sqr_merged_xxx.mp4
- 缺少ffmpeg:安装ffmpeg并添加到系统PATH
