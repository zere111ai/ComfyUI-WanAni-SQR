# [English](README.md) 

## 2026-07-05 更新 — WAN ANI DIRECTOR

### Summary
新增面向 WanAnimate 与 SCAIL-2 分段工作流的可视化导演台，可手动切分参考视频、为每段分配参考图和提示词、控制动作迁移或人物替换，并在排队生成前校准参考图中的人物比例。

### Description

`WAN ANI DIRECTOR` 是专门针对 WanAni SQR 执行方式设计的时间线控制台。它保留原有分段队列、断点续跑、音频处理、过渡接力和最终合并能力，同时将仅支持平均分段的操作升级为可视化编辑流程。

主要功能：
- 自适应参考视频预览，支持播放同步、时间线拖动、精确视频元数据，以及实时响应 `force_rate`、`skip_first_frames`、`frame_load_cap` 和 `select_every_nth`。
- 支持手动 Cut、拖动分段边界、每段最少 60 帧、独立分段颜色、删除后自动补齐，以及 1–100 段的手动平均分段。
- 每段可配置有序参考图组，支持拖拽排序、自适应缩略图、原始分辨率显示、人物/背景标记；后续空段会自动继承最近一段有效参考图。
- 非多参模式只传入第一张参考图，并强制作为普通人物参考；Multi Ref 模式传入完整有序图组，并联动 SCAIL-2 高级 Colored Mask 身份模式。
- 动作/表情迁移与人物替换采用全局控制，自动同步所有分段、Colored Mask Advanced 和 SCAIL-2 过渡节点。
- 每段可填写独立 Positive 提示词，并通过新的 `STRING` 输出连接到工作流；后续空提示词向前继承，第一段必须填写。
- 两种过渡策略：ON 保留视觉与 latent 平滑接力；OFF 让每段按照自己的参考图和连续动作视频帧独立生成，再按精确可见区间硬合并。
- 可在播放头位置提取比例引导帧，并进入参考图比例调整界面；参考图可半透明叠加、拖动、缩放，保存时维持原分辨率，缩小使用灰色补边，放大按原画布裁切。
- 支持每段 Video Combine 实时预览、浏览器 client 绑定、中英界面切换、节点自适应缩放、checkpoint 续跑、音频对齐和最终视频合并。

本次更新同时修改了 Python 节点结构、后端接口和前端扩展，更新后请重启 ComfyUI 并刷新网页。

## 2026-07-01 更新

### Summary
修复 Load Video 起始跳帧偏移，跨工作流记忆最近使用的分段数，并兼容不含音频流的源视频。

### Description

本次更新改进了分段队列的时间轴准确性和日常使用体验：
- 分段任务会保留 `VHS_LoadVideo.skip_first_frames` 的原始设置，并在此基础上叠加每一段的偏移，不再覆盖用户设置。这样跳过开头帧后，不会错误地变成缺少结尾帧。
- 音频切片使用同一套修正后的源视频偏移，保持画面与声音同步。
- 分段数会保存到浏览器本地设置。切换工作流后自动恢复最近一次使用的数值，不再回到默认值 `2`。
- 创建 `VHS_LoadAudioUpload` 节点前会检测源视频是否包含音频流。无音频视频会按静音视频继续运行，不再因音频提取失败而中断。
- 源视频无音频时，会清除完整片段和裁剪片段输出中的无效音频输入。

更新后请重启 ComfyUI 并刷新前端，使后端和界面修改同时生效。

## 2026-06-30 更新

### Summary
新增可断点续跑的文件夹图片批处理、逐张自动排队、节点进度条、底部文字边条，以及按照来源文件夹自动整理输出目录的 Flux.2 Klein 批量重绘流程。

### Description

新增节点：
- `LH Images Folder Loader`：保持每张图片原始尺寸；可记录文件夹图片总数、当前索引、文件清单、当前文件和运行批次。意外中断后会从最后成功保存的位置继续。
- `LH Save Image (Passthrough)`：每张图片保存成功后自动排队下一张；阻止旧任务重复保存；同步更新浏览器预览；支持日期路径，并自动创建“来源文件夹名-f2kmd”输出目录。
- `LH Image Footer Bar`：可控开关；支持白底黑字或黑底白字；可设置文字、边条高度、字号和左右留白；账号及长链接会自动缩小适配。

附带工作流：
- `example_workflows/f2k-reskin.json`：Flux.2 Klein 9B 文件夹批量风格重绘工作流，支持保持画幅比例的约 1.5MP 输出、逐张处理、断点续跑、进度显示、可选署名边条和自动输出目录。

稳定性改进：
- 自动任务携带明确图片索引，避免 ComfyUI 重复使用上一张图片缓存。
- 每次重置生成独立运行 ID，同一个文件夹可以反复完整重跑。
- 仅在图片成功保存后推进断点；旧任务不能让进度倒退或重复保存。
- 排序方式、起始索引和加载上限均纳入独立进度身份。
- 文件夹节点显示当前数量、总数、百分比和当前文件名。
- 本地运行进度文件不会提交到 Git。

一个适用于 ComfyUI Wan Animate / KJ Context 的自动化长视频生成节点,支持分段生成、无缝过渡、自动场景切换、断点续跑、自动合并和音频同步。

## 已整合过渡节点

原独立项目 `SQR-WAN-Transition` 的功能现已直接整合到本项目：

- `SQR WanAnimate Transition To Video`
- `SQR SCAIL2 Transition To Video`
- SCAIL2 动作迁移与 Replacement Mode 独立过渡策略
- 根据模型自动处理过渡视频读取、裁切、合并及音频偏移

安装本项目后不再需要同时启用旧的 `SQR-WAN-Transition` 插件，否则可能重复注册同名节点。

## ✨ 主要特性
- 分段生成:自动拆分长视频,避免显存不足错误
- 无缝过渡:使用上一片段的最后一帧保证流畅衔接
- 自动场景切换:支持多参考图风格/角色切换
- 断点续跑:中断后可从任意片段继续生成
- 自动合并:全部片段生成后自动拼接为完整视频
- 音频同步:自动提取并对齐原视频音频
- 预览模式:先查看分段计划再开始渲染

## 🚀 快速开始
1. 将 Load Video 的 frame_count 和 fps 连接到本节点
2. 设置分段数量,关闭 Run 先预览计划
3. 通过按钮绑定以下节点:
   - 源视频节点 (Load Video)
   - 输出节点 (VHS_VideoCombine)
   - 动作嵌入节点 (WanVideoAnimateEmbeds)
4. 打开 Run 开始自动生成

## 🛠 运行模式
- 预览:仅显示分段计划,不渲染
- 全新生成:从第1段开始渲染并自动合并
- 续跑:从中断处继续生成

## 📌 常见问题
- 节点ID为空:请通过按钮绑定必需节点
- 中断续跑:设置起始片段 → 选择最后视频 → 启用续跑
- 输出路径:output/sqr_merged_xxx.mp4
- 缺少ffmpeg:安装ffmpeg并添加到系统PATH
