# Summary

Add resumable folder image batches, automatic per-image queue continuation, progress display, optional footer branding, and source-aware output folders for Flux.2 Klein workflows.

# Description

This release introduces three image workflow nodes:

- `LH Images Folder Loader` for original-resolution folder loading and persistent sequential checkpoints.
- `LH Save Image (Passthrough)` for save-before-next execution, automatic queue continuation, duplicate protection, live preview routing, and `<source-folder>-f2kmd` output organization.
- `LH Image Footer Bar` for optional white/black branding strips with fitted custom text, social handles, or URLs.

It also includes the `f2k-reskin` Flux.2 Klein 9B example workflow with aspect-preserving ~1.5 MP sizing, interruption recovery, rerun-safe batch IDs, node progress display, and structured output paths.
